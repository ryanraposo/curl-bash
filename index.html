curl-bash

Fetch. Verify. Transact. Recover.

Piper, the pipewright, helps agents build safer curl-pipe-bash installers.

Fetch completelyDownload a versioned archive to a private temporary directory before executing project code.
Verify exactlyCheck artifact identity and SHA-256; optionally require GitHub build provenance.
Transact deliberatelyPreflight, plan, stage, commit, verify, and leave a durable receipt.
Recover honestlyReverse committed changes after failures and preserve prior unmanaged state.
